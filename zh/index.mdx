# AI SDK Harness

harness 章节介绍 AI SDK 的 harness 抽象：一套用于运行 Claude Code、Codex 和 Pi
等成熟智能体 harness 的统一 API。

- [概览](/zh/01-overview)：了解 harness 与 provider、模型、智能体、流以及 UI 基础组件之间的关系。
- [HarnessAgent](/zh/02-harness-agent)：创建会话、运行回合、管理沙箱生命周期，并恢复 harness 对话。
- [工具](/zh/03-tools)：使用内置 harness 工具、由宿主执行的 AI SDK 工具、审批以及沙箱感知的执行。
- [技能](/zh/04-skills)：向 harness 运行时提供可复用的指令包。
- [harness 适配器](/zh/05-harness-adapters)：了解可用的 harness 适配器。
- [工作流工具](/zh/06-workflow-utilities)：将 HarnessAgent 回合作为持久化的 Workflow DevKit 工作流运行。
- [UI](/zh/07-ui)：将 harness 输出流式传输到 useChat，并构建可保留 harness 会话的聊天路由。
- [终端界面](/zh/08-terminal-ui)：借助一个小型会话适配器，在 @ai-sdk/tui 中运行 HarnessAgent。
