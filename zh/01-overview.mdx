# AI SDK Harnesses

AI SDK 的 harness 抽象让你可以通过单一的 AI SDK 接口来运行成熟的智能体 harness。harness（智能体运行框架）是一个完整的智能体运行时，例如 Claude Code、Codex 或 Pi。它拥有的能力超出了模型调用的范畴：工作区访问、内置编码工具、原生会话状态、压缩、权限流程以及运行时专属配置。harness 适配器可以在沙箱中运行该运行时，但其执行环境因适配器而异；使用前请查阅相应适配器的运行时位置与安全指南。

AI SDK 的 harness 抽象与 provider/model（提供商/模型）抽象是相互独立的。Provider 将模型暴露给 `generateText`、`streamText` 等 AI SDK Core 函数；harness 则将智能体运行时暴露给 `HarnessAgent`。

使用 harness 并不意味着放弃自定义能力。`HarnessAgent` 允许你提供自己的指令、技能、AI SDK 工具、权限设置、沙箱初始化钩子以及适配器专属配置，同时保留让每个 harness 强大的运行时行为。

这两个抽象是解耦的，但在可能的情况下会使用兼容的原语。harness 的输出会被投射为 AI SDK 的流式与响应类型，因此消费 AI SDK 模型流的接口同样可以消费 harness 流。例如，你可以将 `HarnessAgent` 的流传给 `toUIMessageStream`，并用 `useChat` 渲染它。该 API 的设计力求让 AI SDK 用户感到熟悉，但 harness 运行时的概念与更底层的语言模型并不相同。配置在适用之处遵循 AI SDK 的模式，在 harness 运行时行为不同的地方则有所差异。

<Note>
  harness 相关包目前处于**实验性**阶段。随着这一早期 API 的进一步完善，不同版本之间可能会出现破坏性变更。
</Note>

## 何时使用 harness

当你希望由现有的智能体运行时来驱动任务时，请使用 harness：

- 能够检查和修改沙箱工作区的编码智能体。
- 拥有自身内置工具与权限模型的智能体运行时。
- 由运行时持有对话历史的多回合会话。
- 应当保留 harness 原生行为、而不是用工具循环重新实现该行为的工作流。

当你希望对模型调用、工具循环、模型设置、结构化输出或自定义智能体架构拥有直接控制权时，请使用 provider 和模型。

## 核心概念

harness 由四个主要部分组成：

- `HarnessAgent`：你在应用代码中使用的 AI SDK 智能体实现。
- harness 适配器：连接到某个运行时的包，例如 `@ai-sdk/harness-claude-code`。
- 沙箱 provider：harness 运行所在的隔离文件系统与进程环境。
- 会话：harness 运行期间活跃的对话与工作区状态。

## 兼容的流

`HarnessAgent.generate()` 返回 AI SDK 的 `GenerateTextResult`。
`HarnessAgent.stream()` 返回 AI SDK 的 `StreamTextResult`。

这意味着你可以消费那些熟悉的字段：

- `result.text`
- `result.stream`
- `result.steps`
- `result.usage`
- `result.responseMessages`

harness 特有的事件会被转换为兼容的流片段。文本、推理、工具调用、工具结果、用量和结束原因在可能的情况下都使用相同的 AI SDK 结构。没有对应一等 AI SDK 片段的事件（例如工作区文件变更和压缩）会以动态的 provider 执行工具片段的形式呈现。

## 会话很重要

与语言模型调用不同，harness 会话持有状态。会话承载了 harness 运行时、沙箱、工作目录、原生对话历史以及待处理的审批。

在执行回合之前先创建会话：

```ts
const session = await agent.createSession();

try {
  const result = await agent.generate({
    session,
    prompt: 'Inspect the repository and summarize the test setup.',
  });

  console.log(result.text);
} finally {
  await session.destroy();
}
```

对于服务端路由，请使用稳定的 `sessionId`，并持久化 `session.detach()` 或 `session.stop()` 返回的恢复状态。
